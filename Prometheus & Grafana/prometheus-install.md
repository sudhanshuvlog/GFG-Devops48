#### Download the latest version of Prometheus

`wget https://github.com/prometheus/prometheus/releases/download/v3.13.5/prometheus-3.13.5.linux-amd64.tar.gz`

#### Untar the downloaded file
`tar -xvzf prometheus-3.13.5.linux-amd64.tar.gz`

#### Move the binary to a directory in your PATH
`cp prometheus-3.13.5.linux-amd64/prometheus /usr/bin`

#### Run the program
`prometheus `
